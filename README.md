# Chat Application

## Introduction
This project is a simple chat application developed in Python using socket programming.  

## Technologies Used
- **Python 3** – Core programming language
- **Socket Library** – For client-server communication
- **Threading Library** – To handle multiple clients concurrently

## Features
- Multi-client chat room.
- Real-time message broadcasting.
- Username support for clear identification.
- Console-based interface for simplicity.
